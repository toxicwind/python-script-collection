## Scripts

| Script | Purpose |
|--------|---------|
| `jwt_forge_kit.py` | Multi-vector JWT token generation |
| `m3u8_fuzzer.py` | HLS manifest analysis & SCTE-35 detection |
| `xtream_probe.py` | Xtream Codes panel enumeration |
| `blobproxy_bypass.py` | JWT bypass testing toolkit |
| `cdp_external_tester.py` | Multi-tier endpoint validation |

## Usage

```bash
git clone https://github.com/toxicwind/python-script-collection.git
cd python-script-collection
python3 jwt_forge_kit.py
```
